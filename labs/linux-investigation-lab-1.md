Lab 1 — Linux on the Desktop

Status: Exercises 1–5 completed
Level: Beginner to Intermediate

Learning Objectives

Navigate Linux directories using the terminal.

Identify the current user and working directory.

Understand file permissions.

Inspect running processes.

Identify listening network ports.

Practice basic Linux investigation.

Exercise 1 — Learn Where You Are

Commands practiced:

whoami — identifies the current user.

pwd — displays the current working directory.

Exercise 2 — Navigate Directories

Document the directory navigation commands practiced and the results observed.

Exercise 3 — Understand File Permissions

Document the file permission commands practiced and what you learned about read, write, and execute permissions.

Exercise 4 — Inspect Processes and Listening Ports

Commands practiced:

ps aux — lists running processes.

ss -tuln — displays listening TCP and UDP sockets.

Two processes observed: To be recorded from actual terminal output.

Two listening ports observed: To be recorded from actual terminal output, if present.

Exercise 5 — Linux Investigation Mini-Scenario

Scenario: A teammate reports an unidentified network-listening service.

Listening port and local address: To be recorded.

Associated process and PID: To be recorded.

Username running the process: To be recorded.

Additional evidence to collect: process command line, executable path, relevant logs, and whether the service is expected.

Incident note: To be completed after examining the actual results.

Key Lessons

Linux commands help investigate users, directories, permissions, processes, and network sockets.

Listening ports are not automatically malicious.

Collect evidence before stopping an unfamiliar service.
